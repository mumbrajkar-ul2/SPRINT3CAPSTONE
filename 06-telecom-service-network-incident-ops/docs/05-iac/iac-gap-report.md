## What this file is

This file lists what the written infrastructure leaves out. A new team needs to rebuild the local environment and get a passing `pytest -q`. This file names each thing that stands in the way.

Half A writes this report. No program file, test, Terraform file, or CI file is changed.

Claim labels: **Verified Fact**, **Inference**, **Assumption**, **Unknown**. A Verified Fact names a file path, a command, or an observed version.

Every secret value in this file is written `<redacted>`. The user name `app_shared` is a name, not a secret value.

## Worked example

Finding IG-05. A new person on Windows follows the README. They create a venv and run `pip install -r requirements.txt`. All six pinned packages install. They run `pytest -q`. Pytest imports `fastapi.testclient`. Starlette 0.38.6 then looks for `httpx`, does not find it, and stops with `RuntimeError`. Three test files fail to load, so zero tests run. One more command, `pip install httpx==0.28.1`, fixes it, and then 15 tests pass (R2).
